# BRICKS

A BRICK is a reusable capability with a defined problem, inputs, workflow, expected output, operator, dependencies, costs, evidence, limitations and last validation date.

Nothing enters this directory as an accepted BRICK merely because it was submitted. The contribution must first satisfy its agreed acceptance conditions and receive independent review.

## From playbook to BRICK

In the Agent Commons, a BRICK is usually a proven playbook packaged as a portable skill folder:

- `SKILL.md` with the instructions and success test;
- any scripts it runs;
- its MCP configuration;
- an `AGENTS.md` memory file;
- its evidence, version and changelog.

It is published here only after it has run on real work, passed independent review and been approved by the steward. Members can then copy it and adapt it.

**First candidate:** Build Zero (voice note → reviewed social post), once its proof link is attached.

See [AGENT-COMMONS.md](../AGENT-COMMONS.md) for how the Commons grows.
