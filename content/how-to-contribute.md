# How to contribute

1. Pick one small, testable improvement.
2. Agree the scope with a maintainer before you build.
3. Open a pull request with your acceptance evidence, cost and limitations.

To build this site on your own computer:

```
python publish.py --src content --out dist
```

Then go back to the [welcome page](../welcome/).
