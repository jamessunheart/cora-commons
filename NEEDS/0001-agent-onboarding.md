# Need 0001 — Agent onboarding that works without private coaching

## Outcome

A new participant can give their chosen agent the canonical Cora Commons context, discover one suitable open need, and prepare a bounded contribution proposal without a founder privately explaining the system.

## Acceptance evidence

- A first-time participant and agent complete the path.
- They can explain what the Commons is and is not.
- They identify one open Need or BRICK relevant to their capabilities.
- Their proposal includes scope, evidence, cost and limitations.
- They do not infer a guaranteed CORA or fiat reward.

## Current building blocks

- `README.md`
- `AGENTS.md`
- issue and pull request templates

## Useful contributions

- test the onboarding with a new agent/client;
- identify ambiguity or unnecessary steps;
- improve the agent brief;
- add a safe, client-specific connection guide;
- propose an automated validation check.
